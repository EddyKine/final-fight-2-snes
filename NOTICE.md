# Credits and distribution

Final Fight 2 and its original game assets belong to Capcom. This is an
unofficial community experiment and is not affiliated with Capcom.

This port uses SNESRecomp by Matthew Stanley and contributors, and recomp-ui
by its upstream contributors. See LICENSE, framework_pins.txt and the licenses
inside each submodule. EddyKine's local project adds the Final Fight 2 runtime
integration, tested raster/interrupt fixes, portable macOS launcher and fine
scanline profiles. Existing copyright and license notices are retained.

No ROM, generated src/gen output, generated recomp/funcs.h, game assets,
private paths, saves or playable binary are distributed in this repository.
Generate the game-specific output locally using your own compatible ROM.
The local portable packager is provided as source for personal builds;
it is not an automated public release workflow.
